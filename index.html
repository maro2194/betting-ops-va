AdsPower Profile Setup

Every working identity needs an AdsPower profile. Format:

MARO - [CODE]

Where [CODE] is the 3-letter code (e.g. LUM, CYS, BIS). For identities without a code, use initials (e.g. FJ for Flordeliza Juera, DM for Dug McNee).

Set proxy in the profile (see Proxies tab). Check proxy works before saving.

Bookmarks (do this for every profile)

Once the AdsPower profile is created, open it and set up bookmarks in this order:

  1. Outlook — Bookmark outlook.live.com but name the bookmark with the profile code (e.g. name it PAA but it links to Outlook). This way you instantly know which email goes with which profile.
  2. Bookies — Add a bookmark for each bookie that's been opened for that ID (TAB, SB, Amused, etc.). Only add bookmarks for bookies that are actually signed up and working.

Example for MARO - PAA:
PAA → outlook.live.com  |  TAB → tab.com.au  |  SB → sportsbet.com.au
